# Plunging into "Detritus"

[(Exercise page)](https://games.brettwitty.net/ifcourse/exercises/detritus/)

We investigate the game *Detritus* by Ben Jackson, focussing on approachability, onboarding, hints and agency.

- [Slow play](./slow-play.md) [(Raw notes)](./slow-play-raw-notes.md)
- Writing exercise: Draft an opening to a game that teaches mechanics without blatant exposition.
- Design exercise: Design a puzzle solvable in two different ways.
- Implementation exercise: Prototype a difficulty switch.
