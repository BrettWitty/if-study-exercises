# Interactive Fiction Study Course Worked Exercises

I'm running [a long-term, free study course in interactive fiction](https://games.brettwitty.net/ifcourse/). Each focus comes with exercises:

- A [slow play](https://games.brettwitty.net/ifcourse/exercises/slow-play/) of a notable IF game examining a particular angle.
- Writing exercise
- Design exercise
- Implementation exercise

This repository has my worked exercises, for all to see.
